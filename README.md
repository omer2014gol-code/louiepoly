# Louiepoly

A Monopoly-style board game set in the Republic of Louie. Buy streets in the Louie cities, build houses and hotels, and grab Asia Town before anyone else does.

Play it here: https://omer2014gol-code.github.io/louiepoly/

- Play on one device with friends or computer players
- Play online: create a room and send the invite link
- English and Hebrew
